Steel Request Parser

Парсер для автоматического сопоставления сметных спецификаций (СЗ) с коммерческими предложениями поставщиков металлопроката и утеплителей.

Описание

Программа выполняет анализ следующих документов:

. Сметная спецификация (СЗ) - перечень необходимых материалов
. Корректировки - изменения количества или размеров (опционально)
. Счета поставщиков - цены и наличие позиций

Результат работы:

. Таблица аналогов.xlsx - сравнение цен всех поставщиков
. Лист согласования замен.xlsx - документ для утверждения замен

Возможности

. Парсинг PDF таблиц и текста
. Извлечение позиций с количеством (штуки, упаковки, погонные метры)
. Сопоставление позиций по типу материала и размерам
. Поддержка OCR для отсканированных документов
. Определение марок стали (Ст3, 09Г2С, С355)
. Обработка упаковок с пересчетом количества
. Экспорт в форматированный Excel с итоговыми суммами

Установка

Зависимости

Установка через pip:

```bash
pip install pdfplumber pillow pytesseract openpyxl
```
